# AI Team Prompts Guide for Shopping Cart Project

Since AI agents automatically discover and follow project rules and skills (`.antigravity/skills/` and `.cursor/skills/`), team members can use these ultra-simple 1-line prompts.

---

## 1. Prompt to Create a Component or Feature

```markdown
Create component/feature [FEATURE_NAME] following our project skills.
```

---

## 2. Prompt to Run Skill Review & Audit Summary

```markdown
Review the latest changes against project skills and provide a summary with bugs, fixes, and verdict.
```
